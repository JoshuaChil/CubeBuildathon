# Enclosure & mount

Put the CAD source (STEP, or a link to Onshape/Fusion) and the printable STL files here.

Requirements:
- The IMU board is screwed or rigidly glued down, so vibration reaches it without damping.
- The button can be reached while riding.
- There is a USB opening for charging and flashing.
- The axis arrows are printed or marked on the lid.
